# Physical AI Book - RAG Chatbot Backend

This is the backend for the "Physical AI & Humanoid Robotics Book" project.
It provides:
- Use of Google Gemini 1.5 Pro for RAG (Retrieval Augmented Generation).
- Qdrant Vector Search integration.
- Personalization API for rewriting chapter content.

## Setup

The backend is built using FastAPI and Python.
It is deployed here as a Docker container.
